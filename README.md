これはGroqを用いたAIエージェントです。AIエージェントを作成した目的としましては、現在大学院生としてLLMやAIをテーマとした研究を考えておりまして、そのなかで簡単に作成できるチャットボットを作成しながら理解を深めるということで行いました。

今回はエンジニア系情報共有コミュニティであるZENNのmizunny様の「無料で使えるLLM API Groqを使ってみた」と
Google社の生成AIエージェントGeminiを参考に作りました。
主にコードはサイトで、エラーやライブラリ等のインストールの問題解決では生成AIを利用しました。
また、Github Copilotはターミナルコマンドの補完とライブラリインストールを行うときの補助として使いました。


まだまだコードの理解が乏しいところもありますので、現在プッシュしたコードからエージェントの原理を勉強しております。
